# Hospital Operations Analytics

A Python analytics project that demonstrates **data cleaning, KPI calculation, aggregation, and healthcare operations reporting** using pandas.

## Business Problem

Healthcare operations teams need reliable reporting on patient volume and service efficiency. This project turns raw patient-visit records into clean, analysis-ready data and department-level KPIs.

## Features

- Standardizes column names and dates
- Removes duplicate records
- Detects invalid wait-time values
- Calculates total visits and unique patients by department
- Calculates average and maximum wait times
- Produces daily visit-volume trends

## Tech Stack

- Python
- Pandas
- Data Cleaning
- KPI Reporting
- Data Quality

## Run

```bash
pip install pandas
python hospital_analytics.py
```
